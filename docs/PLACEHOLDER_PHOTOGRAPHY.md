# Placeholder campaign photography — replacement guide

The theme ships with **no fabricated MAYDAN products or campaign photos**. Where a real
image hasn't been uploaded, it renders a **refined dark placeholder** (a subtle
black/charcoal gradient with a small red glow) and, on campaign areas, a visible label:

> `Campaign image — replace in theme editor`

Replace every placeholder before launch. All are uploaded through the **Theme editor**
(no code). Recommended art direction: cinematic editorial photography, a serious
grappler/fighter in a dark training environment, realistic skin and fabric, dark
directional lighting, negative space for headline text. **Avoid** floating product
cut-outs, tech-pack/mockup images, stock-photo smiles, bodybuilding poses, fake logos,
generated Arabic lettering, swords/lions/mosques/desert clichés, neon or gold gradients.

## Where the placeholders are

| Location | Where to replace | Field |
|----------|------------------|-------|
| **Homepage hero** | Theme editor → Home → Campaign hero | Desktop + Mobile campaign image |
| **Shop by category** tiles | Home → Shop by category → each tile | Image override, or the collection's image |
| **Featured drop banner** (MUHARIB) | Home → Featured drop banner | Campaign image |
| **Email capture** (optional bg) | Home → Email capture | Background image |
| **Collection banners** | Each collection, or Collection template → Banner image | Collection image / override |
| **Image with text** (About) | Page: About → Image with text | Image |
| **Product cards / galleries** | Products → *product* → Media | Real product photos (cards show a branded placeholder until then) |
| **Password page** | Theme editor → (password preview) → Password | Background image |
| **Logo** | Theme settings → Logo | Official MAYDAN logo (do not recreate) |

## Image guidance
- **Hero desktop:** landscape, ≥ 2400px wide, 16:9 or wider.
- **Hero mobile:** portrait crop, ≥ 1200px tall.
- **Category tiles:** portrait 3:4, ≥ 1200px.
- **Drop banner:** wide landscape, ≥ 2400px.
- Export high-quality JP/WebP; Shopify generates responsive sizes automatically.
- Always set descriptive **alt text** on uploaded images for SEO/accessibility.

## The Arabic wordmark
Only upload a **finalized, approved** Arabic graphic (Header → Arabic wordmark). The
theme never generates Arabic type. Leave it empty until you have the approved asset.
